# Bundled item pictures

One picture per Rust Console Edition catalogue item (`<shortname>.webp`, ~160 px), so every item shows up in the
kit builder, the custom-kit list, the web store and the kit pictures without any download.

Source: the community icon set at https://github.com/LehaSex/rust-game-icons (PNG icons extracted from the game,
resized here to WebP). The icons are Facepunch Studios' intellectual property and are bundled only for convenience;
they are not affiliated with or endorsed by Facepunch.

These win over downloaded pictures (old downloads are deleted at start). Your own file in
`data/item_images/custom/<shortname>.png` wins over the bundled one.
