# Price list for custom kits bought in tickets
#
# The ticket AI uses it to tell players the price of their custom kit, and the bot approves a purchase by
# itself when the player's Tip4Serv payment covers the price (Settings -> Tip4Serv store).
# Edit it in the web interface (Shop -> Price list) or here. Changes apply immediately.
#
#   currency EUR
#   item, item = PRICE / AMOUNT                    price per AMOUNT, rounded up to full bundles
#                                                  e.g. "metal.refined = 1 / 200": 1,000 HQM = 5
#   item = PRICE / 1 with item, item               the "with" items are included for free,
#                                                  up to the same amount (e.g. armour with an AK kit)
#   cap N: item, item                              at most N of these items together
#   cap N each: item, item                         at most N of each of these items
#   timer 30h = 0                                  claim timer (cooldown) options; the one costing 0 is
#                                                  the default
#
# Items without a price can still be requested, but then staff has to approve the purchase.
